========================================
IDENTITY SPOOFING DETECTION - QUICK SETUP
========================================

REQUIREMENTS:
✓ Python 3.11 (NOT 3.14)
✓ Node.js 16+
✓ npm

========================================
BACKEND SETUP:
========================================

1. Open Terminal/PowerShell
2. Go to backend folder:
   cd identity-spoofing-detection/backend

3. Create virtual environment:
   python -m venv .venv

4. Activate virtual environment:
   WINDOWS: .\.venv\Scripts\Activate.ps1
   MAC/LINUX: source .venv/bin/activate

5. Install packages:
   pip install -r requirements.txt

6. Start server:
   flask --app app run

✓ Backend running at: http://127.0.0.1:5000

========================================
FRONTEND SETUP:
========================================

1. Open NEW Terminal/PowerShell
2. Go to frontend folder:
   cd identity-spoofing-detection/frontend

3. Install packages:
   npm install

4. Start dev server:
   npm start

✓ Frontend opens at: http://localhost:3000

========================================
TEST THE SYSTEM:
========================================

1. Open: http://localhost:3000
2. Click "Face Test" tab
3. Click "Use Camera" button
4. Allow camera access
5. Take photo → Enroll Face
6. Take photo again → Verify Access
7. See results!

TROUBLESHOOTING:
========================================

Fix: Activate virtual environment!

Problem: Camera not working
Fix: - Use http://localhost:3000 (not IP)
